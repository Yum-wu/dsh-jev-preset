# P1 异构模型路由实证(2026-09-28,Round 2)

## 背景:同模型并发是反模式(实测)

JEV persona §3 原写"同一条 assistant 消息内并发发射 3 个 subagent 即是隔离与并行的物理保证"。
2026-09-28 按该纪律**严格遵守**派发三路,**三路全灭**。经 `tools/audit-subagent-cost.mjs`
核实,三路实际路由均为 `opencodex/opencode-zen/muse-spark-1.3-contributor-free`(**免费档**):

| 子会话 | 路由 | 重试次数 | 限流事件 | turn/end | closing |
|---|---|---|---|---|---|
| `0133ab8d-5d32-4875-b9fe-56f4cbac96d7` | muse-spark(免费档) | 6 | 7 | `RATE_LIMIT` | 无 |
| `c2dd617c-acfe-4fe6-af5c-5050ce404efe` | muse-spark(免费档) | 6 | 7 | `RATE_LIMIT` | 无 |
| `f529f435-a6f6-4f62-8d2b-8515a02e5287` | muse-spark(免费档) | 6 | 7 | `RATE_LIMIT` | 无 |

失败链(从子会话 zstd 日志解出,非推测):
```
[22] assistant/attempt → finish.reason.error = 429 rate_limit_exceeded
[23..39] llm/retry ×6   退避 1.4s → 3.3s → 5.4s → 10.3s → 20s → 20s
[42] turn/end reason=error code=RATE_LIMIT
```
单路耗时约 320 秒,零产出。三路合计约 16 分钟算力全废。

## 修法:异构模型路由(§3.3)

三路各用**不同** provider/model,把并发压力分散到不同上游配额:

| 路 | 路由 | 理由 |
|---|---|---|
| Path 1 严谨推导者 | `opencodex/combo/ds-flash` | 强推理档,需完整中间量 |
| Path 2 红队对抗者 | `opencodex/google-antigravity/gemini-3.8-flash` | **异构模型**才有真对抗价值 |
| Path 3 极简执行者 | 低延迟档(路由不足时串行降级) | 只出最小可跑代码 |

## 验证结果:异构并发 2/2 成功

同一时间点、同一任务(CASE-03 `raw=104.381 tick=0.125 NEAREST_HALF_UP`)、**同消息并发**发射:

| 子会话 | 路由 | 重试 | 限流 | closing |
|---|---|---|---|---|
| `f1807136-6ac6-4a8d-acab-cc4c58beb500` | `combo/ds-flash` | 0 | 0 | `[Path 1 严谨推导者]` |
| `e23737cc-9200-4940-a694-3d3183b875ac` | `google-antigravity/gemini-3.8-flash` | 0 | 0 | `[Path 2 红队对抗者]` |

两路均**零重试、零限流、正常结算**,并各自回显路标身份。

## ⚠️ 混杂因子声明(不得过度归因)

上表对比**存在 confound**,不能单独归因于"异构":

| 组 | 路由档位 | 结果 |
|---|---|---|
| 失败组(3 路) | muse-spark **免费档** | 3/3 限流失败 |
| 成功组(2 路) | ds-flash + gemini-3.8-flash **付费档** | 2/2 成功 |

**两个变量同时变了**:①路由是否异构 ②模型档位是否付费。
免费档被上游更激进地限流是**同样合理的解释**,本实验**无法区分**二者贡献。

因此当前可确证的结论只有:
- **免费档同模型并发三路 → 必挂**(3/3 复现,机制明确:429 + 重试耗尽)。
- **付费档异构并发两路 → 通过**(2/2)。

**未确证**:付费档**同模型**并发三路是否也会挂。要分离该变量,需补做对照实验
(付费档同模型并发 3 路 ×N 次)。在该实验完成前,persona 中的"同模型并发是反模式"
应读作**保守纪律**(宁可不冒风险),而非已被完整证明的因果结论。

## 执行断言裁决(最高仲裁权)

| 方案 | 样本 | 结算成功 | 限流失败 | 结论 |
|---|---|---|---|---|
| 免费档同模型并发 | 3 | 0 | 3 | **否决** |
| 付费档异构路由并发 | 2 | 2 | 0 | **采纳(保守)** |

数值一致性:两路对同一任务的结论**独立且一致** ——
Path 1 得 `ticks_count=835 / valid_price=104.375 / tick_diff=+0.006`;
Path 2 独立给出中点 `104.4375/0.125=835.5` 的 HALF_UP vs HALF_EVEN 分歧档位
(`835` vs `836`,差 0.125),以及 float 漂移与 0.01 截断两类反例。
两者不冲突,且 Path 2 补充了 Path 1 未覆盖的中点平局边界。

## 成本观测(新工具 `audit-subagent-cost.mjs`)

异构后各路成本差异显著(单次同类任务):

| 路由 | 输入 tok | 输出 tok | LLM 耗时 |
|---|---|---|---|
| `combo/ds-flash`(Path 1) | 11,518 | 1,596 | 14.2s |
| `google-antigravity/gemini-3.8-flash`(Path 2) | 132,160 | 1,045 | 28.3s |

同样任务下 gemini 路由输入 token 约为 ds-flash 的 **11 倍**(缓存命中结构不同)。
这为"哪一路该用贵模型"提供了首个量化依据:Path 1 需要完整推导,值;Path 3 只需最小代码,不值。

## 副产品:两个机读化审计工具

1. `tools/audit-subagent-settlement.mjs` —— 结算健康度(限流/重试/无 closing),退出码 1 即告警。
   首版有假阴性(`s.chunk.finish.reason` 误写为 `.failure` 路径),经与原始日志逐字段比对修正:
   `0133ab8d` 等三例由 `rateLimit=0` 变为 `rateLimit=7`,检出恢复。
2. `tools/audit-subagent-cost.mjs` —— 按路由聚合 token/耗时,并提示是否启用异构。
   本文件对失败组路由的**修正**正是该工具发现的(原记为 ds-flash,实为 muse-spark 免费档)。

## 结论

1. **免费档同模型并发 = 必挂**,已写入 persona §3 顶部警告(实测 3/3)。
2. **付费档异构路由并发 = 通过**(实测 2/2),且提升实质独立性(不同模型权重)。
3. **混杂因子未分离**:付费档同模型并发尚未测。persona 的"异构"要求按**保守纪律**执行,
   后续应补对照实验确认因果边界。
4. 降级路径明确:2 路由→部分串行;1 路由→全串行并标 `[JEV: 串行降级-单路由]`。
5. 成本已可量化(工具 2),路由分配策略从"凭感觉"转为"凭数据"。
