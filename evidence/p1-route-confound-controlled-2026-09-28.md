# 对照实验:分离"路由异构性"与"档位付费"两个变量

**日期**:2026-09-28
**动机**:`evidence/p1-heterogeneous-route-round2.md` 中发现混杂因子 —— 失败组(免费档)
与成功组(付费档)同时变了两个变量,无法归因。本实验补做对照,分离变量。

## 实验设计

| 组 | 路由配置 | 样本 | 目的 |
|---|---|---|---|
| 失败组(已有) | `muse-spark-1.3-contributor-free`(**免费档**)同模型 ×3 | 3 | 基线 |
| **A 组(本实验)** | `combo/ds-flash`(**付费档**)同模型 ×3,重复 3 轮 | **9** | 分离"同模型"变量 |
| 成功组(已有) | `ds-flash` + `gemini-3.8-flash`(**付费档异构**) | 2 | 对照 |

A 组每轮间隔 90 秒(遵守上游 RPM/TPM 限制),prompt 极简化以压低 TPM 占用。

## 结论:混杂因子已分离

| 配置 | 样本 | 结算成功 | 限流失败 |
|---|---|---|---|
| 免费档 + 同模型并发 | 3 | 0 | 3 |
| **付费档 + 同模型并发** | **9** | **9** | **0** |
| 付费档 + 异构并发 | 2 | 2 | 0 |

**真凶是免费档,不是"同模型"。**

- 付费档同模型并发 3 路**完全可行**(9/9,零限流)。
- 免费档(muse-spark)被上游激进限流,同模型并发 3 路必挂(3/3)。
- 异构路由**对限流并非必需**(付费档同模型已够),但仍有**独立价值**:不同模型权重
  才有真正意义上的"独立验证",而非同源偏见。

## 对 persona 纪律的修正

原警告文本过度断言("同模型并发是反模式")。修正为:

1. **真正的红线**:不要在**免费档/限流敏感路由**上并发发射多路。
2. **付费档同模型并发是可接受的**(已实测 9/9),不再是禁止项。
3. **异构路由仍为推荐**(提升独立性),但降级为"推荐"而非"硬要求";
   若为省成本想同模型,在付费档下可以。
4. 保留 `list_subagent_models` 前置核实与串行降级规则。

## 三路数值一致性(三组 9 路交叉验证)

同一任务 `104.381` 按 `0.125` 网格对齐,9 个独立子会话结论:

| 结论 | 出现次数 | 路由 |
|---|---|---|
| `835` / `104.375`(ticks / valid_price) | 9 | 全部 |
| 附带指出"835.5 前提数本身有误,真中点应为 `104.4375`" | 3(A1/A2/A3 的 Path 2) | 全部 Path 2 |

**9/9 数值一致**,且 Path 2 三轮独立地纠正了 prompt 中"835.5"的错误前提
(`104.381/0.125 = 835.048`,真中点须 `104.4375`)。这既是三路一致性的正面证据,
也说明红队角色确实在**质疑题目前提**,而非顺着 prompt 走。

## 实验局限

- 样本量:免费档仅 3 次(受限于当时的失败即中止),付费档 9 次。免费档基线样本偏小。
- 未测:免费档 + 异构路由(是否异构就能救免费档?未验证)。
- 未测:三路以上并发(4/5/6 路)的付费档表现,当前只证明 3 路可行。
- 限流与上游账户配额、时段、并发总负载相关,结论具**时效性**,非永久常量。
