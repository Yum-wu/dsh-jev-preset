# JEV 能力边界(Capability Boundary)

**日期**:2026-09-28
**性质**:基于本仓**已实证**数据,划清 JEV 三路隔离采样的适用与不适用边界。
**原则**:每条边界都附实测数据与出处;**未验证**的一律标注,不推断。

---

## 一、一句话结论

> **JEV 三路隔离采样能防"随机错误",防不住"系统性盲区"。**
> 前者靠多路采样有效,后者必须靠**异构基座模型**或**外部工具约束**。

---

## 二、边界总表

| 场景 | 三路是否有效 | 实测证据 | 建议 |
|---|---|---|---|
| 数值计算(公式明确) | ❌ **无增益** | C0 单路已 97.5%(`DIFFICULTY-CALIBRATION.md`) | Fast-Pass 直出 |
| 随机性算错/笔误 | ✅ 有效 | 三路交叉可发现分歧(设计目标) | 用三路 |
| **审题/注意力盲区** | ⚠️ **有限**(+33pp,不显著) | candy 题 11.1%→44.4%,p=0.25(`CANDY-C1-VS-C3.md`) | **优先换模型** |
| 同模型系统性盲区 | ❌ **无效** | 5/9 题三路收敛到同一错值 | 换异构模型 |
| 需要外部事实/工具 | ❌ 无效 | 未测(三路都是纯推理) | 用工具 |
| 成本敏感场景 | ❌ **负收益** | C3/C1 = 18.7 倍(`CANDY-C1-VS-C3.md`) | Fast-Pass |

## 三、关键实测数据(全部来自本仓)

### 3.1 三路 vs 单路:审题陷阱题

| 配置 | 正确率 | 盲目率 | 成本/题 |
|---|---|---|---|
| ds-flash C1(单路) | 11.1% | 89% | 14 万 |
| ds-flash C3(三路) | 44.4% | 56% | 263 万 |
| **gemini C1(异构单路)** | **100%** | **0%** | 75 万 |

**结论**:换模型 **+89pp / ×5.4 成本**;加路数 **+33pp / ×18.7 成本**。
**换模型在正确率与成本上双双占优。**

出处:`CANDY-CROSS-MODEL.md`、`CANDY-C1-VS-C3.md`

### 3.2 天花板效应:常规数值题上三路无空间

首轮 C0(纯推理、禁工具、最弱基线)对 **39/40 = 97.5%**,
难度筛选 `[0.2, 0.8]` → **kept = 0**(无一题有区分力)。

**结论**:常规数值题上 C1/C3 最多比 C0 高 2.5pp,**跑三路是纯浪费**。

出处:`DIFFICULTY-CALIBRATION.md`

### 3.3 同模型多路 = 共享盲区(不是独立验证)

ds-flash 三路在 **5/9** 道陷阱题上各自独立跑,却**收敛到同一错值**(26/27/28/23/20)。

**结论**:这不是随机错误,是所有实例共享的**注意力弱点**。
三路"一致"在此类缺陷上**毫无保护作用** —— 印证行为纠缠研究
([arXiv:2604.07650](https://arxiv.org/abs/2604.07650))。

出处:`CANDY-CROSS-MODEL.md` 第四节

### 3.4 免费档并发 = 必挂(运营边界)

| 配置 | 样本 | 成功 | 限流失败 |
|---|---|---|---|
| 免费档(muse-spark)同模型并发 | 3 | 0 | **3** |
| 付费档(ds-flash)同模型并发 | **9** | **9** | **0** |
| 付费档异构并发 | 2 | 2 | 0 |

**结论**:红线是**档位**,不是"同模型"。免费档并发三路必挂(429 + 6 次重试耗尽,单路烧 ~320s)。

出处:`evidence/p1-route-confound-controlled-2026-09-28.md`

### 3.5 递归阻断有效(结构性边界)

`maxDepth: 1` 端到端实证:孙会话数 = **0**,引擎抛 `SubagentDepthError`。

出处:`evidence/p0-depth-limit.log`

### 3.6 门控行为正确

C3 在 9 道陷阱题中 **8/9** 派发了子代理(`[4,3,3,0,3,3,3,4,3]`),C1 严格 0/9。

**结论**:persona 的路由纪律本身有效(该走三路的确实走了)。

出处:`CANDY-C1-VS-C3.md` 第三节

## 四、决策树(可直接照用)

```
任务进入
  │
  ├─ 是否依赖"读懂题干细节/隐含条件"?
  │    └─ 是 → 【换异构模型】,而非加路数
  │           理由: candy 实测 换模型 +89pp / 加路数 +33pp(不显著)
  │
  ├─ 是否需要外部事实/工具验证?
  │    └─ 是 → 【用工具/执行断言】,三路纯推理无效
  │
  ├─ 是否数值计算且公式明确?
  │    └─ 是 → 【Fast-Pass 单路直出】(C0 已 97.5%,三路无空间)
  │
  ├─ 是否先验高危(资金/风控/安全/重构)?
  │    └─ 是 → 【三路 + 执行断言】
  │           · 三路必须异构(优先项)
  │           · 路由档位:禁止免费档并发
  │           · 执行断言权重 > 三路共识
  │
  └─ 其他 → Fast-Pass
```

## 五、成本参考(实测单价)

| 配置 | token/题 | 相对成本 |
|---|---|---|
| ds-flash C1 | 140,171 | 1.0x |
| ds-flash C3 | 2,627,544 | **18.7x** |
| gemini C1 | 753,089 | 5.4x |

**推论**:C3 只在"先验高危 **且** 三路确实有增益"的场景才划算。
在审题类缺陷上,它两样都不满足。

出处:`CANDY-C1-VS-C3.md`、`CANDY-CROSS-MODEL.md`

## 六、未验证 / 待补(明确标注,不推断)

| 项 | 为什么重要 | 验证方法 |
|---|---|---|
| **样本量仅 9 题** | 所有 candy 结论都需 ≥50 题复核 | 扩题后重跑 C1/C3 |
| **仅两个模型** | 不能推广为"gemini 优于 ds-flash" | 加第三个模型(如 opus)对照 |
| **gemini C3 未跑** | 单路已 100%,C3 无空间(有意省略) | 若要验证"三路在弱模型上是否更有效"可跑 |
| **3 题成功机制未核实** | 推测某一路发现提示,未读日志 | dump 子代理日志逐字确认 |
| **三路对"随机错误"的有效性** | 设计目标,但本仓**未构造随机错误实验** | 构造已知易错题,看三路是否捕获分歧 |
| **异构模型间的行为纠缠程度** | 只引用他人度量,本机未测 | 构造同步失败集,算 BEI/CIG |
| **补派上限=1 是否最优** | 保守取值,未做对照 | 1/2/3 次上限对照实验 |
| **`docs/performance-spec.md` 门槛值** | 拍定目标值,无测量依据 | 真实三路实测回填 |

## 七、对 JEV 设计的净影响

| 项 | 改动 |
|---|---|
| 异构路由 | 从"推荐"**升级为"优先项"**(附实测数据) |
| 同模型多路 | 明确其**硬边界**:只防随机错误,防不住系统盲区 |
| Fast-Pass 门槛 | 得到成本数据支持(18.7x,简单题负收益) |
| 执行断言优先 | 得到理论支持(行为纠缠 → 共识≠正确) |
| 补派预算封顶 | 得到 MASFT FC3 支持 |
