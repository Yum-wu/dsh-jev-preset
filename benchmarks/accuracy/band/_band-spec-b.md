# B 线题集 —— 「朴素界错」造题契约(2026-10-15)

## 一、为什么再造一批(A 线失败后的换路)

A 线(`_band-spec.md`)用「**1 个易漏限定**」做难度旋钮,造出 7 族 125 题。
实测筛选 105 题 × 3 模型 × 3 reps ⇒ **20–80% 难度带命中 0 题**(唯一 1 题是噪声)。

⇒ 结论:**「读得到但容易漏读」这个旋钮不产生难度**。分布是二元的 —— 要么 100%,要么像
`trap_candy` 那样 0%。

B 线换难度来源:不再靠「读题」,改靠「**建模**」。

## 二、难度旋钮(唯一许可)

**每题埋一个「朴素界」:一个看起来完全合理、但错误的直觉解。**

- 朴素解 = 把题面数字**直接加总 / 按比例外推 / 用单一公式套一遍**
- 正确解 = 必须**正确建模**才拿得到:
  - **最坏情况构造**(鸽巢/minimax):问「最少取多少才能**保证**」时,
    正确做法是构造**最大的不满足目标的集合**,再 +1;朴素做法是简单累加。
  - **守恒量建模**:比例变化时抓**不变量**(如含水率变化 → 干物质质量守恒),
    朴素做法是线性外推。
  - **极值可达性**:问「最大/最小」时必须验证该值**是否真的可达**,
    朴素做法是只算上界不验证可达。

**禁止**靠「易漏限定」制造难度 —— 那已被 A 线证否。本题族里所有约束都要写得**显眼**,
读到就一定不会漏;难的是**知道该建什么模**。

**禁止**靠大数运算制造难度 —— 数字要小到能手算,难度只能来自建模选择。

## 三、硬约束(违反即废题)

1. **唯一数值答案**,可程序化判分。
2. 题面**自包含**:不依赖网络、外部文件、实时行情。所有输入写进题面。
3. 题面用**中文**。
4. 题末必须带作答格式块,**与现有题集逐字同构**(三个反引号包住的 json 块):

   ```
   【作答格式(判分程序只读这一段)】
   回复最后必须给出一个 ```json 代码块,内容为单个 JSON 对象,键名严格如下:
   {"<键名>": "<值>"}
   所有数值一律写成字符串(如 "123.45"),按题目要求的精度与舍入,不要带单位或千分位。
   ```

5. 每题的 `expected` **必须由独立 solver 脚本复算得出**,**不得手写**。
   - ⚠ **solver 与 expected 必须异构**:solver 必须**独立重算**(暴力枚举 / 第二套公式),
     **不得**只是把 expected 抄一遍。A 线出过事故:有批次**把 solver 改成迁就一个错误的 expected**。
   - **最坏情况构造类题必须用暴力枚举交叉验证**(规模要小到能枚举完),solver 里两套解法都要有。
6. 不得与现有题集重复 —— **改数字不算新题**,必须换陷阱类型或换场景。

## 四、输出(每批次两个文件,放 `benchmarks/accuracy/band/`)

### 1) `<name>.jsonl` —— 每行一个 JSON 对象,单行不换行

```json
{"id":"<category>-20261015-<NN>","category":"<category>","kind":"numeric","question":"<题面,含作答格式块>","expected":{"<键名>":"<值>"},"suite_version":1,"seed":20261015}
```

- `id` 形如 `<category>-20261015-00` … `-19`(两位数,从 00 起)
- 题面里的换行写成 `\n`
- **额外字段**(B 线专属,用于事后判定模型是否命中朴素值):
  `"naive": "<朴素直觉解的字符串值>"`

### 2) `solvers_<category>.py` —— 独立复算脚本

- 读同目录 `<name>.jsonl`
- 对每题**从题面文字独立重算**(**不要**直接读 `expected` 当答案)
- 逐题打印 `OK <id> <值>` 或 `MISMATCH <id> expected=<e> solver=<s>`
- 退出码:全部 OK = `0`;有 MISMATCH = `1`
- 另需打印 `NAIVE_DISTINCT <id> ok=<True|False>` —— 校验朴素值 **严格不等于** 正确值
  (相等 = 该题陷阱无效 = 废题)

## 五、必交证据

真跑 `python solvers_<category>.py`,**贴出原始 stdout 与退出码**。
不贴 = 未完成。solver 与 expected 必须全部一致才可交付。
另贴:每题 `naive` 值 vs `expected` 值的对照表(证明陷阱有效)。
